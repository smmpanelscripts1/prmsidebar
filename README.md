# PRM Sidebar

Blueprint extension for Pterodactyl / Blueprint.

Moves the client top navigation and in-server SubNavigation into a left sidebar that follows the admin panel look.

- Dashboard, Admin, Account, Sign Out, and Search in the sidebar
- `/server/{id}` tabs (Console, Files, Databases, and Blueprint extras) in the same sidebar
- `/account` tabs in the same sidebar
- Collapse / expand with the header toggle

## Version

`1.0.0`

## Install

Copy into Blueprint extensions and run `blueprint -install prmsidebar`.
